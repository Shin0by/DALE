## Product invariants

- JPG/JPEG + Foundry scene JSON input; Foundry 13/14 supported. Same-stem JSON opens automatically. Separate JSON command replaces current JPG's wall source, directly or from a .dale JSON catalog chooser. Offer save/discard before replacement; preserve extracted asset lifetimes.
- No legacy support. Current .dale schema is 2. Reject older/unknown versions. No migrations, retired-mode aliases, shared-size fallbacks, or compatibility adapters. Foundry 13/14 support is a separate requirement.
- Every edge has persistent ID, parent lineage, exact source references (JSON SHA-256, original /walls/index, optional Foundry ID). Splits create children; merges union parents; new lines inherit contact ancestry. Detached manual lines are editor roots. Moves/extensions preserve identity; shared-wall clones become children. Contact nodes expose incident/parent/source references. Persist ancestry in operation/redo snapshots. Never guess ancestry from historical coordinates.
- .dale stores exact JPG/JSON, declared original/updated JSON catalog, history/redo, ancestry, settings. Validate bounds, member whitelist, hashes, values, lineage; save atomically. Never overwrite source assets or write geometry into Foundry JSON. See docs/project-format.md.
- Coordinates use original image pixels. Preview never limits export resolution. Masks are immutable alpha snapshots. Region transforms change geometry only; raster stays in place.
- Export separate native RGBA crops. Only Artwork offset remains in the Regions left numeric tile, signed -4096..4096 source pixels; it changes retained JPG pixels relative to lines. No mandatory 3px guard or global transparent-padding parameter. Render alpha with minimal 2x supersampling/bicubic reduction and filter halos, preserving native RGB. Crop from every nonzero final alpha pixel (including 1/255), clamp to JPG. Shared exact bounds for Information/export, stripe processing and bounded cache. All-regions uses current connected components; explicit selection exports minimum cells.
- Three sets: Contours / Regions / Raster. Two text-only top rows: general commands, then sets + Hand/Fit/Walls. One left column, ordinary buttons 48x48, numeric buttons 48x72 with icon/editable caption/gray arrows. Each eraser has own size. Snapping inside Contours only. No footer/default map tooltip. Minimum 1024x768. Right Information and Settings hold all map/export/count/settings/language data. No visible height/origin controls.
- Closed cyan, open pure red RGB(255,0,0). Cosmetic black 3px backing + colored 1px center; white hover side edges preserve centers. Selected cells translucent cyan. Walls off hides all inactive geometry and handles in every tool; retain only selected cell boundaries/fill in region tools, highlighted lines/points, and current gesture previews. Never redraw inactive centerlines while painting white highlights.
- Auto-close traces cursor lines and reachable continuations. Extend existing free tips forward along vectors to intersections; no sideways moves/standalone bridges. Facing collinear tips meet halfway; node T/shared contacts. Own 1-256 screen-pixel tolerance. Immediate Cancel/Yes dialog; Yes commits one GeometryEdit. Close all contours repeats across graph with separate tolerance. No retired Closure/Alt-click tool.
- Point handles: fixed 10-screen-pixel circles, pointing-hand hover, insertion spacing one diameter. Alt-drag constrains to approached segment vector, toggle mid-drag. Shared nodes move together. Degree-two deletion reconnects neighbors; branches remove incident edges. No dedicated T policy.
- New line press/drag/release. Snapping 0-256 screen pixels, vertices first. Geometry erasers sweep circular footprints, preview white deletion targets, independent 1-512 screen-pixel sizes. Raster Erase/Restore independent 1-4096 source-pixel sizes. Escape cancels.

Move regions asks whether to include transitively related lines within ordinary snap tolerance; Remember choice optional; right-click reopens. No excludes branches and preserves stationary neighboring shared walls. Move regions: drag translates, Ctrl+wheel scales. Separate Rotate regions button: plain wheel rotates 0.1 degree per notch about one stable common center; no Alt gesture. One undo per transform; raster unchanged.

Never run snapping, auto-close or line extensions toward stationary geometry during a transform. Record the owner report without claiming it fixed until regression evidence exists.

- Atomically merge portable preferences: language, Foundry major, related-line choice, one input directory (JPG/JSON/project opening), one output directory (PNG/project saving). Never remember extraction paths.
