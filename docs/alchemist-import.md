# Local Dungeon Alchemist import

The inspected private maps use DAM JSON Version6 and Version11; these input formats are separate from the unchanged DALE schema7. The files remain immutable and are never uploaded.

## Local evidence

Version6 contains53 walls,753 objects,950 building-block instances and3 foundations. Version11 contains221 walls,1716 objects,2611 instances and63 foundations across layers -1 through3, including rotated foundations and9 curved walls. Both maps resolve all referenced object IDs using the locally installed built-in and Workshop descriptions. Four Version6 rock instances use negative scale.

Objects reference buildingBlockInstanceId. Instances carry blockId, center, placement height, scale and rotation; foundationId provides foundation/layer context. Family information is not reliably carried by that placed-object record. BuildingBlocks.json supplies displayCategoryIds, names, keywords, modelId, scale/offsets and optional manualColliderSet. ModelStaticData.json supplies collider/render dimensions. Downloaded Workshop descriptions provide configs and staticData under Steam's local content/1588530 folders.

The importer recognizes the installed Tree, Plants and Rock display category IDs. Tree takes priority where categories overlap. Other object families do not generate obstacles. DAM wall records supply wall geometry independently of those object categories. The importer resolves descriptions before changing the dataset; unknown resources are not guessed.

## Geometry and limits

Initial registration maps the complete DAM width/height onto the dataset's original image extent and flips the vertical axis. Foundation-local walls additionally apply foundation rotation and mapPosition. This assumes the attached image covers the complete corresponding DAM map; cropped, independently shifted or differently exported imagery may need contour alignment in the editor. Straight-wall midpoint checks against placed instances agree within5.5e-6 map cells in the inspected new file.

Trees use the lowest available collider as a trunk footprint. Plants use their render envelope and rocks use collider bounds. Generate circular polygons from these dimensions, with instance/model scale and offsets. These are editable obstacle proxies, not exact mesh silhouettes or a physics simulation. Minimum size uses the original proxy diameter in DAM grid cells; wall size uses its source chord length. Manual collider rotations are not reconstructed. Curve conversion interprets DAM curvature as signed quarter-turn units; its visual match should be reviewed for unusual wall assets. Wall and object elevations come from local metadata and placement, converted using the Scene grid distance; missing distance uses5 scene units per cell. No live Foundry rendering claim is made.

The SQLite cache stores resolved block/model descriptions by ID and format version. It avoids rereading the installation on cache hits. Clear it after local asset updates when fresh descriptions are required. Existing DALE projects store their generated geometry and exact DAM source and remain independent of that cache. This module has no HTTP client, Steam download invocation or game-library write path.


## Height above surface and progress

The old sample contains a753x521 BSON height grid; the new sample contains a361x433 float32 grid after11 texture blocks. Both provide8 subdivisions per map cell and include endpoint samples. Source world top minus bilinear local relief estimates protruding height; building foundations use their own floor height. Measurements use5 feet per DAM cell, independent of the Scene's output distance units. This is an estimate from model envelopes at the placement center, not a mesh/terrain intersection or clearance under the object. It includes raised objects and clips fully buried objects to zero. Unusual model pivots, tilted models and large objects spanning steep terrain can make the estimate less accurate.

Each category has Minimum height above surface, integer0..10 feet. Zero includes all;3 includes objects whose estimated original top reaches at least3 feet above the surface. Scale and shape edits do not change this measurement. Visibility, original diameter and original height filters combine, and excluded objects stay out of combined views and JSON export. Lowering thresholds restores their edited contours. Opening/importing projects shows progress. Ordinary DA editing does not open progress windows or prepare export data; local drawing caches and recently computed region analyses are reused. Exact export preparation runs when requested.

The pinned [UnityPy reader](https://github.com/K0lb3/UnityPy) decodes native meshes. GLB buffers are embedded only. No Workshop assets or textures are downloaded. Bands clip model triangles and close cut caps before top projection. Choose each object's band from local relief/floor and placement; negative scale is supported. Sample the ground near the actual band centroid rather than the bounding-box center. Dense vegetation gets a concave envelope, not individual leaf holes; rocks retain meaningful concavities. Texture alpha is now evaluated before external outlines are generated (ADR-120). Animation/custom shaders, state variants and steep/irregular terrain remain approximation limits. Fully buried/empty bands emit no obstacle; below-model surfaces select the basal band. Tree crowns can participate at high surface levels.

The progress preview uses material tint and shading on opaque surfaces over the alpha-corrected mask; transparent cards do not cover that mask; the previous image/name remain paired until the next complete band is ready. Cache profiles/previews locally and keep generated geometry in the project.

## Model and project memory lifetime

Retain the native reader across uncached models in one batch, but release each model's decoded arrays and preview intermediates immediately after its ten projections are stored. Break recursive traversal closures so input buffers do not wait for cyclic garbage collection. Close local Unity reader files at batch completion. Check process resident memory between models; after two growing samples, collect only when retained growth exceeds128MiB. Restart the reader if the growth remains, or if available RAM is below256MiB with at least32MiB retained growth. Stable readers stay warm. These are process-level pressure signals, not an exact attribution of all allocations to UnityPy. Keep persistent 2D profiles in SQLite; never purge that cache during normal editing.

Finished progress workers drop Python results, operations, exceptions and preview buffers before deferred Qt deletion. Map closing releases derived drawing/ownership caches. JSON-only DA information reuses cached foundation-floor choices instead of building a height band for every object tip. Project validation parses only catalog documents actually referenced by authored additions. No working-set trimming or per-gesture forced collection is used.

Closing model-projection import or pressing Escape requests cooperative cancellation. Keep the progress dialog and last preview visible while the current native call finishes; check between triangle batches, projection bands and import stages. Reject cancellation even after a worker has returned, before publishing its result. Partial contours never reach the dataset; close local readers and roll back pending profile-cache writes. Other noncancellable progress dialogs hide their close control and preserve preview updates until completion. DA category settings use available space below their tool button, showing all content when it fits and keeping Apply/Cancel outside the scroll area.

## Reversible object thinning

Select trees, bushes and rocks together, then enable Thin objects. The inline number and Ctrl+wheel set strength0..10; when enabled, Ctrl+wheel over the map also changes it. The calculation compares real intersections across the selected types. Nearby objects that do not touch are preserved. Medium strength favors redundant interior coverage while retaining exposed cluster edges. Strength10 leaves only mutually disjoint objects within the working selection. The result is approximate coverage, not a guarantee of the same outer perimeter.

Removed objects are hidden, including from PNG/JSON exports, but their geometry stays in the project. Zero restores them. Hidden objects remain part of the current thinning scope when selection is pruned. A new unrelated selection starts a new scope and replaces the previous filter. Each dataset remembers its applied scope/strength; undo and project reopening preserve the result. Background recalculation shows progress and discards superseded values.

New DAM imports now include the game's default180-degree Object model rotation, block rotation and complete offset/scale composition. Existing project contours retain their exact saved placement. Reimport the DAM to correct contours generated by older versions; no cache clearing is necessary.
