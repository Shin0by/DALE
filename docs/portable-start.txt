DALE — Dungeon Alchemist Levels Export

ENGLISH
Open DALE.exe; keep the whole folder including _internal. No Python needed.
File > Open scene loads a scene image and scene JSON; Open project resumes a .dale project.
File > JSON loads a scene JSON directly or selects one from a DALE project document list.
Old project formats are not supported.
Menus: File / Edit / About. File > Recent projects remembers ten opened/saved projects.
Top: Sections (Contours / Regions / Raster), Scene (Levels), Main (square icons).
Main > Settings opens its separate right page. Levels opens level and wall-preset definitions.
Scene keeps left tools visible. Add/Delete buttons manage cards; double-click edits; eyes hide levels.
Level heights are whole feet: empty bottom/top means -/+infinity. RGB offers16 colors/full palette.
Import/Export templates transfers definitions only, including import from another current .dale.
Project format is3; older projects are unsupported. Without a scene, Save exports template JSON.
Project nests Regions, then File information. Each right page has the same bottom Information.
The left editing toolbar has a single frame.
The global-settings checkbox follows Language. Bottom Information shows active gestures
and every available window shortcut, including Undo/Redo, file commands, Fit and clear selection.
Right-drag pans; wheel zooms. Hover help explains tools and shortcuts.
Sizes/tolerances are inside tool buttons; Ctrl+wheel changes them.
All eight numeric values save in the project. Store settings globally copies current values
to UserData/settings.json; enabled globals survive opening projects. Disable to restore project values.
Clear selection follows Hand; Ctrl+Shift+A clears selected regions and contour highlights.
Auto-close and Close all contours show white previews and Cancel / Yes confirmation.
No-op explanations have only Close. New circular contour: press center, drag radius, release.
The polygon changes live: 0.5/1/2 cells in diameter use 4/6/8 vertices, then density grows.
Ctrl+wheel adjusts radius while drawing; Escape cancels; one undo step on release.
Regions selects individual cells. Move regions drags geometry only; Ctrl+wheel scales;
Select Rotate regions, then ordinary wheel rotates 0.1 degree around common center.
Right-click either transform tool to configure related lines.
Show contours off hides inactive lines/handles; only selection and current tool highlights stay visible.
Raster Erase/Restore have independent diameters. Save stores sources, history, redo, ancestry.
Input/output folders are remembered independently.
Left Artwork offset adds/cuts actual JPG pixels relative to lines. No global padding setting.
PNG alpha uses light bicubic smoothing; exact bounds include every nonzero alpha pixel.
placement.json records coordinates. Configure height in Foundry.
Minimum 1024 x 768. UserData/settings.json retains preferences.
Preserve projects during updates. Open editors retain their version until restarted.

РУССКИЙ
Запускайте DALE.exe; переносите всю папку с _internal. Python не нужен.
Файл > Открыть сцену загружает изображение сцены и JSON сцены; Открыть проект — файл .dale.
Файл > JSON загружает JSON сцены напрямую или из списка документов проекта .dale.
Старые форматы проектов не поддерживаются.
Новый круглый контур: нажать в центре, тянуть радиус, отпустить. Грани меняются сразу:
диаметр 0,5/1/2 клетки даёт 4/6/8 вершин, затем число растёт. Ctrl+колесо меняет радиус,
Escape отменяет. Если автозамыкание ничего не меняет, в окне есть только «Закрыть».
Меню: Файл / Правка / О программе. Файл > Последние проекты хранит десять проектов.
Сверху: Разделы (Контуры / Области / Растр), Сцена (Уровни), Основное (иконки).
Шестерёнка открывает панель настроек. Уровни — шаблоны этажей и пресеты стен.
Слева инструменты остаются видимыми. Добавить/Удалить управляют карточками; двойной клик меняет их.
Высоты — целые футы, включая0. Пустой низ/верх — минус/плюс бесконечность. Цвет:16 вариантов/RGB.
Глазик скрывает содержимое уровня. Пресеты стен не имеют высоты; поля меняются по выбранным режимам.
Импорт/экспорт шаблонов переносит только общие настройки, в том числе из другого проекта .dale.
Формат проекта3; старые проекты не поддерживаются. Без сцены сохранение выгружает JSON шаблонов.
В Проекте — Области и Данные файла. Внизу каждой правой панели одинаковая Информация.
Слева одна рамка панели инструментов.
Галочка глобальных настроек следует за языком. Нижняя Информация показывает
действия текущего инструмента и общие горячие клавиши, включая Ctrl+Z и Ctrl+Y.
Правая кнопка перемещает карту; колесо меняет масштаб. Подсказки поясняют горячие клавиши.
Размеры и допуски встроены в кнопки; Ctrl+колесо меняет их.
Все восемь числовых значений хранятся в проекте. «Хранить настройки глобально» копирует
текущие значения в UserData/settings.json; открытие проекта их не заменяет. Снятие галочки
возвращает значения проекта. «Снять выделение» после «Руки»; Ctrl+Shift+A.
Автозамыкание и Замкнуть всю карту показывают белый кант и подтверждение Отмена / Да.
Области выбираются по отдельности. Перемещение меняет только контуры:
Ctrl+колесо — масштабирование. Кнопка Вращение областей — обычное колесо по 0,1°.
При отключённом показе контуров видны только выбранные области и активная подсветка.
Правый клик по инструменту снова открывает вопрос о связанных линиях.
Ластик и восстановление растра имеют собственные диаметры.
Проект хранит исходники, историю, повтор и происхождение линий.
Папки открытия и сохранения запоминаются раздельно.
Слева Отступ изображения добавляет/срезает пиксели JPG относительно линий. Общей рамки нет.
PNG сглаживает альфа-край через bicubic и включает все ненулевые альфа-пиксели в границах JPG.
Высоту задавайте в Foundry. Минимум окна 1024 x 768.
Настройки — в UserData/settings.json. Открытый редактор использует свою версию до перезапуска.

Exact PNG dimensions for large scenes calculate in the background; editing stays available.
Точные размеры PNG больших сцен рассчитываются в фоне, редактирование остаётся доступным.
