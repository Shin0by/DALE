DALE portable for Windows x64

Window title: Dungeon Alchemist Levels Export (v.x.xx.xxx).

Open DALE.exe. Python installation and command scripts are not needed.
Keep DALE.exe and the complete _internal folder together. To move DALE,
copy this entire folder, including UserData if you want to keep preferences.

Switch English / Russian using Language in the footer.
Hover over buttons and settings for help. The right panel can be scrolled.
Open JPG + JSON to start, or open a saved .dale project to continue.
Ctrl+S saves the original files, editing operations and Undo/Redo history.
Top row: unframed text commands. Second row: tool set, Hand, Fit, and Walls.
The selected tools appear left of the map as square icon-only buttons.
Line/vertex erasers contain separate size captions and small gray side arrows.
Each eraser button is 1.5 times normal height; click its number to type a size.
Their independent diameters are saved in .dale projects.
Pixel size and Snapping (px) remain left tiles with numbers and minus/plus buttons.
Hover over controls for localized help, tool names, and applicable hotkeys.
Auto-close traces related lines: white edges show the affected group.
Its embedded number/arrows and Ctrl+wheel set its independent extension limit.
Click extends existing lines along their vectors to intersections in one undo step.
Dashed continuations preview the repair; no standalone connectors are created.
Use New line for larger gaps. The former Closure tool and Alt-click are retired.
Closed contours are cyan, open contours pure RGB (255, 0, 0) red.
Lines are 3 screen pixels: black edges around a 1-pixel color center.
Minimum window: 1024 x 768. The footer uses one row.
The selected Foundry version and language are remembered between launches.
Select a region in the footer to see its guarded dimensions and export only it.
Export creates separate PNGs with 3-pixel guards and placement.json.
placement.json is a DALE coordinate reference, not a Foundry scene import.
Configure image positions and elevation in Foundry separately.

DALE portable для Windows x64

Заголовок окна: Dungeon Alchemist Levels Export (v.x.xx.xxx).

Запустите DALE.exe. Устанавливать Python или запускать скрипты не нужно.
Файл DALE.exe и папка _internal должны находиться рядом. Для переноса
скопируйте всю эту папку; UserData содержит настройки, включая язык.

Язык переключается внизу окна: English / Русский.
Наведите курсор на кнопку или параметр для подсказки. Панель прокручивается.
Откройте JPG + JSON либо сохранённый проект .dale.
Ctrl+S сохраняет исходники, изменения и историю отмены/повтора.
Первый ряд сверху — текстовые команды, второй — набор, Рука, Вся карта и Стены.
Выбранные инструменты находятся слева от карты: квадратные кнопки с иконками.
У ластиков линий и точек отдельные числа размера с серыми стрелками по бокам.
Кнопки выше обычных в 1,5 раза; нажмите на число, чтобы ввести свой размер.
Независимые диаметры сохраняются в проектах .dale.
Размер пиксельной кисти и Прилипание (px) — слева, с числом и минус/плюс.
Подсказки элементов поясняют назначение, название инструмента и его горячие клавиши.
Автозамыкание трассирует линии: белый кант показывает затрагиваемую группу.
Число, стрелки в кнопке и Ctrl + колесо задают собственную дальность продления.
Клик удлиняет существующие линии по векторам до пересечения одним шагом отмены.
Пунктир показывает продолжения; отдельные соединительные отрезки не создаются.
Для больших зазоров есть Новая линия. Прежние Замыкание и Alt + клик удалены.
Замкнутые контуры голубые, незамкнутые красные с RGB (255, 0, 0).
Линии — 3 пикселя: чёрные края вокруг цветного центра в 1 пиксель.
Минимум окна: 1024 x 768. Футер занимает один ряд.
Выбранные версия Foundry и язык запоминаются между запусками.
Выберите область внизу окна для просмотра её габаритов и отдельного экспорта.
Экспорт создаёт отдельные PNG с запасом 3 пикселя и placement.json.
placement.json содержит координаты DALE, это не импорт сцены Foundry.
Координаты и высоту размещения задайте в Foundry отдельно.
