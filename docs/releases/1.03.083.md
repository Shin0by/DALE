# DALE 1.03.083

Windows x64 portable release. The owner promotes the application to1.03 while retaining revision083. The source package version is1.3.83; the application title displays v.1.03.083. Current DALE project schema7 remains unchanged.

## Editing and selection

- Separate Vertices, Contours, Regions and Raster workflows with mode-specific selection and shortcuts.
- Contour move, rotate, scale, mirror and application-wide copy/paste with a stable vertex or common-center attachment point.
- Explicit Alt alignment controls, adjacent right angles, axis references and arbitrary-angle contour guides.
- Independent Raster objects transform imagery and their own regions without altering scene contours.
- Bounded undo/redo, per-dataset camera state, grouped selections and transparent holes in region groups.

## Raster and export

- Native-resolution visible tiles backed by a portable, bounded, cleaned disk cache.
- Round/square erase and restore brushes with size, feather and opacity controls.
- Exact transparent PNG crops, stable selection identifiers, native dimensions in filenames and optional JSON companions.
- Shared configurable grid with per-dataset RGB, transparency and cosmetic line thickness; exact grid-aligned transparent padding after artwork offset.
- Preview uses the same region/mask composition rules as PNG export. Source images and scene JSON remain unchanged.

## Interface

- Main contains Hand, Select all, Clear selection, Copy, Delete and Settings.
- View contains display controls, rulers/guides, scene grid, background and native resolution.
- A single horizontally scrolling top row supports a1024x768 minimum window.
- Nonmodal staged tool settings and a persistent project-wide16-slot Custom Colors palette shared by all color pickers.
- English and Russian interface/help.

## Portable package

Download DALE-1.03.083-Windows-x64-portable.zip and extract the complete DALE folder. Run DALE.exe; no installed Python is required. Keep _internal beside the executable. The archive contains the runtime, startup notes, bundled licenses and build provenance, with no user preferences, projects, private examples or cache. Preserve your existing UserData folder when updating.

Scene levels, wall/floor presets, portals and generation of new native Foundry Scene settings remain outside this release. Configure these manually in Foundry. Older DALE schema versions are not supported.
