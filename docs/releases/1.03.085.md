# DALE 1.03.085

This update adds Windows product discovery for the portable application.

- Normal packaged launches record product name, version, publisher, repository,
  actual EXE path, stable Shin0by.DALE product ID and UTC launch time under
  HKCU\Software\Shin0by\DALE.
- DALE.exe is also registered in the current user's App Paths key.
- Identical machine-wide entries are attempted only with existing access. No
  administrator prompt, permission change or installer is introduced.
- The last normally launched portable copy updates the recorded path/version.
  Python/development and smoke-test launches leave these keys unchanged.
- Registration failures do not prevent the editor from starting. Settings remain
  in portable UserData, and the current DALE project schema7 is unchanged.

The repository now also contains the complete ready DALE folder on development
and release. Clone or download it and run DALE/DALE.exe directly; local UserData,
cache and projects remain excluded from Git.

The release also includes the existing group sorting, contour editing, Raster
tools and exact PNG export features. See [Windows product discovery](../windows-registration.md)
for the complete registry value contract.

Download DALE-1.03.085-Windows-x64-portable.zip, extract the complete DALE folder
and run DALE.exe. No installed Python is required. Keep _internal beside the EXE.
The archive contains runtime files, startup notes, licenses and build provenance;
it excludes UserData, projects, private examples and cache. Preserve your existing
UserData when updating. A SHA-256 checksum accompanies the archive.
