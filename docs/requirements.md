# Product requirements

Owner scope replacement2026-10-17 (ADR-020): DALE edits one scene image and its optional source contour JSON, repairs/joins/closes contours, cleans alpha and exports separate native RGBA PNGs for all connected closed objects or selected minimum cells. Every PNG filename includes its exact final width and height in pixels. Levels, wall/floor presets, composition, portals, native Scene export and Foundry runtime configuration are cancelled; the owner configures these manually in Foundry. Earlier plans are historical, not a backlog.

Acceptance criteria describe required behavior; validation evidence is recorded separately in project/state.json. Stable IDs are retained even for cancelled requirements.

Narrow extension2026-10-17: ADR-021 / FR-076..078 permit automatic inferred-height-layer repair and a coordinate-only copy of the original Scene JSON. This supersedes only conflicting PNG-only/no-JSON-output criteria. It does not restore cancelled composition/preset/Scene-generation features. The implementation adds JSON-only input, safe repair mode, typed history and coordinate-only atomic export; validation is recorded in project/state.json.

## Source JSON repair

| ID | Requirement | Acceptance criterion |
| --- | --- | --- |
| FR-076 | Infer vertical repair layers from original wall heights. | Derive processing bands from finite native height bounds in scene units; treat demonstrated missing/null Wall Height bounds as unbounded while preserving source values. Build connectivity independently in band interiors, without joining adjacent ranges at their shared boundary. One canonical source wall/ID is referenced in every covered band; spanning walls are never cloned or split into native records. Identical XY is not sufficient to deduplicate source walls. These bands are not authored levels/floors. Ambiguous/invalid/zero-thickness cases are retained and reported, without guessed heights or silent normalization. |
| FR-077 | Reconcile shared walls across all their repair layers. | Generate layer-specific directional joining proposals but store one coordinate pair per original endpoint/ID. Validate a common-wall edit in every covered layer, even layers with no proposed repair; preserve existing joins. Resolve compatible proposals as one atomic change. If no consistent solution exists within direction/tolerance/contact constraints, keep the complete dependent conflict group unchanged and report it. No first/last-layer overwrite, arbitrary floor priority, native duplicate/split/merge or accidental cross-floor door contact. Undo restores all affected canonical coordinates together. |
| FR-078 | Export applied walls while preserving all other Scene data. | With source Scene JSON, export the active dataset's full applied walls, regardless of filter/selection. Allow movement, insertion, splitting, erasure, point deletion, merging and manual additions. Preserve exact bytes outside the root walls array, including lights, tiles, tokens, regions, portals, paths, names and unknown data. Reuse original wall text/coordinate-token patches where possible. Retain properties and IDs through explicit source ownership; split children inherit settings and unique stable IDs, merged ownership retains distinct property sets. Contact ancestry never copies unrelated settings. New walls use ordinary defaults; no Scene defaults regenerated. Inverse coordinate conversion, BOM/format outside walls, atomic new-copy publication, source/hash/hardlink protections remain. No live Foundry import guarantee. |
