# Editing workflow

Launch DALE/DALE.exe with the complete _internal folder. No Python needed. Minimum window: 1024 x 768. Hover help explains every control and its shortcuts.

1. Image + JSON (Ctrl+I) opens JPG and same-stem JSON automatically, otherwise asks for JSON. Open (Ctrl+O) resumes a current .dale project. Older project formats are rejected.
2. JSON replaces walls for the current JPG after offering to save edits. Ordinary JSON opens directly; a .dale opens a separate original/updated JSON list. It does not import that package's image/history. Cancel preserves current work.
3. Two text-only top rows contain general commands, then Contours / Regions / Raster, Hand, Clear selection (Ctrl+Shift+A), Fit (F), Walls. Clear selection removes selected regions and contour highlights, cancels previews and keeps the current tool/map unchanged. One left column contains active tools; numeric tools embed editable numbers/arrows. Right blocks: Project (file/map/export/counts), Regions (selection dropdown), Settings (target/global scope/language), Information (current tool gestures and all enabled window shortcuts). Bottom help updates with mode/language/availability and scrolls independently if needed. No footer/default map tooltip.
4. Wheel zooms at cursor. Right-drag pans everywhere; Hand also supports left-drag. Closed cyan/open pure red RGB(255,0,0). Three-screen-pixel strokes have a colored center and black side edges. Hover previews turn edges white. Walls off hides inactive lines and point handles in every tool. In region tools only selected cells stay outlined/filled; in contour tools only highlighted geometry/current gesture remains.
5. Contours > Auto-close traces cursor lines and eligible connected continuations. Independent distance 1-256 screen pixels. White edges/dashed extensions preview; click opens Cancel / Yes before mutation. Yes extends existing lines along vectors to intersections in one undo step. Facing collinear ends meet halfway; T targets split. No standalone connectors/sideways movement. No-op repairs explain their result.
6. Close all contours performs the same directional repair across the graph, with separate distance and confirmation. Snapping (px) is independent, 0-256 screen pixels, vertices first. Its icon toggles snapping; its number adjusts tolerance. Available only in Contours.
7. New line uses press/drag/release. Edit points inserts, drags fixed 10-screen-pixel circles, deletes on double-click. Nearby existing points are selected rather than duplicated. Alt-drag projects onto the approached segment's original vector; release Alt for free motion. Shared nodes move together; normal point deletion reconnects two neighbors, branches remove incident edges.
8. Erase lines / Erase vertices have independent 1-512 screen-pixel diameters and white deletion previews. Fast drags sweep the full path; one undo per gesture. Escape cancels. Ctrl+wheel changes active tool size or the numeric button under cursor.
9. Regions > Select regions toggles the smallest closed cell under cursor. Other clicks add/remove; empty clears. Touching rooms are not implicitly selected. Selection fills translucent cyan. Export selected regions exports each cell separately. Left Artwork offset retains additional JPG artwork outside lines for positive values or cuts inward for negative values (-4096..4096 source pixels). Arrows/direct input/Ctrl+wheel adjust it.
10. Move regions asks Move all connected lines? Yes includes transitively related lines within ordinary snap tolerance. No keeps branches/shared walls of stationary neighbors. Remember choice persists; right-click reopens. Move regions drag translates; Ctrl+wheel scales 5% per notch. Select the separate Rotate regions button in the left Regions panel, then use ordinary wheel to rotate 0.1 degree per notch about one stable common center, without zooming. Wheel up is clockwise, down counterclockwise. Right-click either transform tool to configure related lines. Alt-wheel rotation in Move regions is removed. Raster/mask snapshots stay in place. Escape cancels drag; Undo restores transforms.
11. Contour offset expands positive/contracts negative, shown dashed cyan. Raster > Remove outside / Remove inside applies a mask snapshot after reviewing unresolved lines. Reapply after geometry changes. Erase / Restore change alpha with independent embedded 1-4096 source-pixel diameters. No snapping control in Raster.
12. Save (Ctrl+S) stores exact sources, geometry/ancestry, masks/strokes, undo/redo, selection and tool state. Save as (Ctrl+Shift+S) creates a checkpoint. One input folder serves JPG/JSON/project opening; one output folder serves PNG/project saving. Both survive restart independently.
13. Export (Ctrl+E) honors selection; All regions exports current connected objects. Current Artwork offset applies even after an earlier outside-mask snapshot; brushes and inside masks remain effective. Alpha edges receive minimal bicubic smoothing, with native JPG color detail unchanged. Automatic crop includes every nonzero alpha pixel (even 1/255), then clips to JPG bounds. There is no automatic 3px guard or global transparent-padding parameter. No overlays in PNG. Progress/cancellation and new destination folders protect existing outputs.
14. Read placement.json for crop/scene positions. Configure elevation/visibility in Foundry. Foundry 13/14 selection is remembered; PNG metadata does not create levels. Live placement remains unverified.
15. All eight numeric tools retain independent values in saved .dale projects. Right Store settings globally is off by default. Enable it to copy current values into the portable config and remember further typing, arrow and Ctrl+wheel edits across restarts. Opening a project keeps global numbers while enabled; disabling restores that project's own numbers. Saving while global settings are active preserves the project's separate numbers. Language/version/folders keep their existing independent storage.

Action labels explicitly identify their subject: Auto-close contours, Edit contour points, New contour line, Erase contour lines/points, Contour snapping, Region artwork offset, Select/Move/Rotate regions, Export selected regions, and raster-specific erase/restore/inside/outside operations. Russian selected export is "Экспорт выбранных областей". Hover help includes the same subject and actual keyboard gestures.

Source JSON is unchanged. Exact JSON SHA-256 and /walls/index identify source walls. Splits inherit ancestry, merges retain all parents, contact lines inherit parents. Detached manual lines are editor roots. See project-format.md.

Development: .venv/Scripts/python.exe -m dale. After changes run checks and tools/build_windows.ps1 to refresh root portable delivery.
