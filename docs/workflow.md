# Editing workflow

Open **DALE/DALE.exe** on Windows x64. Keep the executable and its `_internal` folder together; no Python installation or launch script is required. Copy the entire portable folder when moving the application. The right panel scrolls; switch English/Russian with the footer dropdown and hover over controls for help. Language and target Foundry version are retained in `UserData/settings.json`. The minimum window is 1024 x 768.

1. Export JPG + Foundry scene JSON from Dungeon Alchemist. Keep equal canvas sizes and grid origins across floors. Keep the complete ground-level JPG unchanged as the base map. With **Open pair** (Ctrl+I), select the upper-floor JPG: DALE automatically opens the sibling JSON with the same stem. If it is absent, choose a JSON in the fallback picker. Resume a **.dale** file with **Open project** (Ctrl+O).
2. The first top row contains unframed text commands for general actions. The second row contains **Lines and vertices**, **Pixels**, **Hand**, **Fit**, and **Walls**. The selected tools appear left of the map as one column of square icon-only buttons. Below them, the diameter and **Snapping (px)** tiles each have an icon, centered number, and visible minus/plus controls. Hover to see the applicable eraser/brush name and units; click the magnet to toggle snapping. The compact dark-gray theme uses outlined, filled tools. Closed regions are cyan; unresolved/open lines are pure RGB (255, 0, 0) red. All map strokes are 3 screen pixels: black 1-pixel edges around a 1-pixel color center, independent of zoom. Inspect walls and alignment. Wheel zooms at the cursor; hold the right mouse button and drag to pan in every tool. Hand also supports left-drag. **Fit** (F) shows the complete map. **Walls** toggles geometry overlays.
3. For padded scenes, enter the actual **Scene origin X/Y** in source-scene pixels and apply alignment. The editor does not guess padding offsets. Applying alignment starts a fresh session after offering to save current work.
4. Set **Join gaps up to (px)** to connect small gaps automatically; 0 disables joining. Distances use source pixels. End-to-end and end-to-middle T junctions work; exact T intersections need no tolerance. Joins use the same closed/open color classification. Red unresolved geometry can also be unused internal/exterior lines.
5. Choose **Closure** for manual repair. Plain click near a working wall to snap the start, Alt-click for free corners, then plain click near a working wall to snap the end. The unfinished red path is editor-only; after completion it receives the same closed/open classification as other lines. Escape cancels unfinished input.
6. Choose **Edit points**. Click a line to add a point; drag a circle to move; double-click a circle to delete. Circles always have a 10-screen-pixel diameter and show a pointing-hand cursor. Clicking within one diameter of an existing point selects it instead of adding a crowded duplicate. Shared nodes move together. **Junction deletion** chooses retaining the straightest continuation or removing all incident edges. Use **New line** to press for the first endpoint, drag, and release for the second. The left Snapping (px) tile controls enablement and distance in screen pixels; vertices have priority over line interiors, both when creating and later moving points. **Erase lines** and **Erase vertices** use a circular screen-space eraser: touched line segments are removed whole, while vertex removal follows the junction policy. Each drag is one undo step; Escape cancels the gesture. Ctrl+wheel changes active tool size anywhere in the window, or adjusts the size/distance control under the pointer. Undo restores geometry; original JSON stays unchanged.
7. Set **Contour offset (px)**: positive expands, negative contracts. A dashed cyan line shows the effective boundary. **Remove outside** keeps interiors; **Remove inside** erases them. Repair missing closed regions first. Review unresolved lines before explicitly continuing with a mask. Excessive inward offset is rejected. Masks are snapshots: undo the old mask and apply a new one after geometry/settings changes; settings alone only update preview.
8. **Erase** paints transparency; **Restore** recovers source opacity. Brush diameter uses source pixels. Each stroke, closure, mask, or completed point edit is one undo step. Undo/Redo shortcuts are Ctrl+Z/Ctrl+Y. Checkerboard areas are transparent.
9. **Save project** (Ctrl+S) writes a self-contained ZIP-based `.dale` file with exact JPG/JSON, operations and redo history, geometry/placement, viewport/tool state, language, and unfinished closures. It loads without the original source paths. Finish mouse drags before saving. **File > Save project as...** (Ctrl+Shift+S) creates a checkpoint. PNG export does not replace project saving.
10. Choose Foundry 13 or 14 and integer **Elevation (ft)**. The selected Foundry version is remembered between launches; loading a project restores its saved version as the current choice. Presets run from -20 through 100 ft in 5-ft steps. Custom whole feet support 1-ft precision and negative heights; fractions are rejected.
11. **Export PNGs** (Ctrl+E) creates a new subfolder in the selected destination. Each disconnected closed region gets its own cropped PNG; adjacent rooms become one object. Choose **All regions** or a numbered region in the footer; a single selection is highlighted and limits export to that region. The single-row footer shows map size, current closed/open counts, and exact guarded dimensions for one PNG (or the largest PNG when exporting multiple regions). Open counts mean connected groups of unresolved lines, not a count of individual wall segments. Every crop retains native resolution and adds a mandatory 3-source-pixel guard beyond the user offset, including source pixels around the wall. Pixels beyond the source are transparent. Editor overlays are excluded, source assets unchanged. Progress/cancellation are available.
12. Read `placement.json` for each PNG's source and scene X/Y/width/height and intended elevation. Position parts over the base map using these coordinates and configure elevation/visibility in Foundry. Foundry 13 tile/module workflows differ from Foundry 14 native Scene Levels. PNG metadata and the DALE manifest do not automatically configure a Foundry scene. Live installation verification remains pending.

The reduced preview does not constrain output resolution. The 3-pixel guard is applied during export beyond the preview mask. Missing roof footprints cannot be recovered from gap tolerance alone. Trace them manually with New line and endpoint snapping; automatic boundary reuse across floors remains future work.

For development only, run `.\.venv\Scripts\python.exe -m dale`. A `.dale` path or `--image <JPG> --scene <JSON>` can preload data. After every project update, run checks and refresh the portable folder with `tools/build_windows.ps1`; preserve `UserData` and user files.
