# PNG contour editor workflow

DALE prepares separate transparent PNGs from one source image at a time. Level assembly, wall types, heights, presets, lights and portals are configured manually in Foundry. See ADR-020.

1. Open DALE/DALE.exe. File > New project (Ctrl+N), the first File command, starts an empty project with one dataset. Unsaved changes use the standard Save/Discard/Cancel question. Open Dataset manager with the button left of the dataset selector or Ctrl+I, then add a scene image (JPEG, PNG, WebP, BMP or TIFF) or Scene JSON to the selected set. A same-stem JSON opens with an image imported into a completely empty set. JSON is optional. Add/Replace JSON also offers original/current documents from a current .dale archive. Apply or Open dataset commits the staged changes.
2. Check alignment and closed/open contours. Vertices provides point editing, new lines/circles, line/point erasers and vertex-first snapping. Closed lines are cyan, unresolved lines red. Shared points move together; Alt applies only enabled angle/contour alignment buttons (below). Each edit preserves source ancestry and undo/redo.
3. Join gaps with directional Auto-close near the cursor or Close all contours across the map. Each has its own tolerance and a white preview followed by Cancel/Yes; no-op dialogs have only Close. They extend or shorten free tips along their line vectors to intersections within the tool's tolerance, with separate counts in the confirmation. Retractions stop at existing contacts and never collapse/reverse a wall. Shared walls retain every covered-layer joint. No sideways bridges are added. NEXT-009 remains an open report about region-transform isolation.
4. Regions selects minimum closed cells; click toggles, empty space clears. Move/scale/rotate changes geometry, leaving raster fixed. Artwork offset retains/cuts source pixels around boundaries. Remove outside/inside applies an immutable alpha mask. Raster Erase/Restore cleans opacity; original source alpha is the upper bound.
5. Choose All regions for connected closed objects, or select individual cells and use Export selected regions. Every output is a separate native RGBA PNG, cropped to every nonzero final alpha pixel, including faint bicubic edges and clipped to the source image. Filenames include exact output dimensions, for example map-<selection-number>-702x702px.png (multiple parts add a stable part number). Information uses the same exact bounds. The named <family>-placement.json records source/scene XY and dimensions for manual placement, without heights or gameplay settings. Export is cancellable and atomically publishes a new folder.
6. Save a current schema7 .dale to retain exact source bytes, contours, mask snapshots, strokes, ancestry, undo/redo, selection and settings. Older formats are rejected without migration. Recent projects lists up to10 successful paths. Copy the whole portable DALE folder; keep UserData/settings.json for preferences.

Top panels are Sections (Vertices/Contours/Regions/Raster), Main (Hand, Select all, Clear selection, Fit, Show contours, Settings) and Dataset (manager icon and set selector). Right Project contains Regions/File information; Settings contains language/global numeric settings. Both include the same contextual Information block. Ten numeric values retain independent project/global scope. Ctrl+wheel changes the active/hovered numeric value (Move regions scales); Rotate regions uses plain wheel. Right-drag pans in every tool. Escape cancels gestures; Ctrl+Shift+A clears selection without editing. Actual command shortcuts are listed in Information/tooltips in English/Russian. No level/preset/property-brush navigation remains.

Button hover help separates Purpose, Condition and Keys. The purpose explains the outcome, conditions state required selection/data/toggle state, and keys are listed with their effect. Numeric buttons include units; hovering their value field explains only that value. Help wraps to a readable width and does not accumulate repeated descriptions when switching language or mode.

Each dataset remembers its camera position and zoom. Dropdown switching and manager Open/Apply restore its latest view. Saving the project stores every dataset camera, including inactive ones; reopening starts with the last selected valid dataset at its saved position/zoom. A new view without saved camera settings retains its initial fitted frame. Repeated switching does not accumulate pixel drift.

Edit contours by height layers filters visible wall editing. It does not disable erasers, point insertion/deletion or any geometry tool. Export JSON retains all other Scene data in every editing mode; only the current walls change. New lines/circles/rectangles work in All with ordinary unbounded wall defaults; choosing a range assigns those bounds. Split parts inherit original wall properties; manually drawn walls start with ordinary defaults. Original files remain unchanged.

## Repair contours by source height

Dataset manager can add Scene JSON before loading an image. JSON-only input and paired native wall-height input enable Edit contours by height layers in File information. Height bands are inferred from original wall bounds, with one canonical wall shared across every band it spans. Missing/null module bounds are unbounded; adjacent ranges only touching at their height boundary are processed separately.

In Contours, right-click Move contours to configure Select contour by double-click (enabled by default). Double-click selects only the hit connected contour, replacing any earlier selection. Double-click empty space clears all selection. Repeating on the same contour keeps it selected; a single click retains the current selection for moving. The option belongs to the dataset and is saved in the project.

Scale contours has a percent step field beneath its icon, initially5, adjustable from1 to100. With this tool active, plain wheel scales the selected contours and Ctrl+wheel changes the step. Move contours uses the same step for Ctrl+wheel scaling. A positive tick multiplies size by1+step/100; a negative tick divides by the same factor. Right-click also opens the standard staged settings. The value follows project/dataset settings and Store settings globally. Move contours shows a pointing finger until contours are selected, then an open hand.

In Vertices, Alt plus right-angle alignment can make an independent endpoint perpendicular to a nearby stationary line without joining them. Alt plus contour guides lets a free end of a lone line follow its original vector within the guide tolerance. Existing X/Y guide acquisition remains available. High-resolution image tiles keep loading when the viewport moves during drawing, dragging, selection or raster painting. The line eraser stops at the same projected T contacts recognized by closed-region analysis.

Use cursor Auto-close or Close all contours, review the highlighted proposals and confirm Yes. The UI tolerance is in screen pixels and depends on zoom. A repair retains native IDs and wall records; internal intersections do not become exported fragments. Conflicting groups remain unchanged and the dialog reports their original contour numbers (one-based). Invalid height bounds are also retained/reported. Each accepted repair is one undo step, preserved in schema7 history/redo.

Point dragging and New line are available here. Choose a height band or exact range in the right dropdown; shared walls participate without clones. Point movement follows overlapping-height contacts, keeping independent coincident floors fixed. New lines/circles/rectangles use ordinary wall defaults and the selected range, or unbounded heights in All. Insertion, deletion, splitting and both geometry erasers are available; inherited wall settings are preserved. Each manual drag/new line is one undo step. Disable the checkbox to edit all contours together. Original source bytes remain frozen in the project. Export JSON preserves all other native Scene bytes/settings in this mode, changing only the walls array.


## Reuse contours and align points

File > Export JSON… (Ctrl+Shift+J) always saves the current contours of the active dataset, including unsaved ordinary geometry changes or safe repairs. All current lines are included regardless of height/region selection or contour visibility; redo, raster masks and Artwork offset are excluded. It works without an input JSON. The proposed physical filename uses the dataset name. Export does not switch sets, save the project or clear undo/redo. Finish/cancel active gestures first. Imported inputs, the open project and their hardlinks cannot be overwritten. When source JSON exists, export retains all non-wall Scene bytes in every mode; without source JSON, export writes a DALE contour snapshot. The same Export JSON command always uses the active set, never the project root or another catalog document. The old Export repaired JSON label has been replaced.

Dataset manager > Scene JSON > Add/Replace > choose a current .dale > Current contours (DALE) > Import loads applied contours, including existing schema7 projects without resaving. Save JSON copies the selected document without importing. This snapshot is for DALE, not a complete Foundry Scene. Original/stored JSON stays available separately.

Enable either/both alignment buttons in the left Vertices panel, then hold Alt while dragging a point. Right-angle alignment checks all line pairs at the moved vertex. Its right-click At adjacent vertices checkbox defaults on and also checks every direct neighbour, including both sides and branches; switch it off to square only the dragged joint. In a quadrilateral, moving one corner can square any of the three affected corners. Own right-angle priority selects the preferred constraint category within the angular tolerance; compatible angles and guides combine. Every accepted angle has highlighted legs and a square marker. The leg leading to the moved vertex stays highlighted even with the joint offscreen. References follow the actual contour, including rotated contours, and exclude hidden layers and independent coincident objects. Contour alignment projects X/Y to vertices in the same connected contour/region, using thin dashed guides. Right-click sets angular tolerance1..90 degrees (default5), unaffected by zoom/line length. The separate contour-guide tolerance remains1..9999 screen pixels (default14); Ctrl+wheel also adjusts these values. Both buttons default off. Release Alt for ordinary movement; Escape cancels. Numeric settings follow project/global precedence; toggles save with the project.


## Manage named datasets

The top Dataset toolbar contains one dataset dropdown and a36px manager button on its left. Each set owns optional current contours/JSON, one scene image, independent edits/redo, source ancestry and project tool values. Switching the dropdown opens both components together. Open the Dataset manager (Ctrl+I) for the approved tree/properties interface.

Create empty sets; rename the set or each file independently. Delete JSON removes its current contours while retaining the image; delete image retains contours. Last-set deletion leaves a new empty set. The first remaining set opens on the next project launch. File commands that manipulate components have moved into this manager; New/Open/Save project, Recent projects, quick Export JSON/PNG, Close project and Exit remain in File. Dataset manager has no File menu entry; its toolbar button and Ctrl+I remain available.

Drag a JSON/image child onto another set, or use Transfer. Choose Move, Copy or Cancel. Occupied destinations offer replacement; Scene JSON also offers Merge contours to append current contours while keeping the source set. A copy is independent; a move clears only that source component. Transfer uses current contours or raster edits, retains exact provenance, and does not automatically rescale coordinates for a differently sized image. A component import freezes source bytes. Apply commits the staged manager changes to the working project; Cancel discards unapplied work. Open dataset applies and activates the selected set. Save project writes every set, including inactive/empty ones.

Merge contours appends imported contours, preserving existing edits, line identities and raster. Full duplicate coordinates/properties may skip; different heights, doors and flags coexist. It creates one combined current JSON. In Preserve JSON mode, imported additions keep their exact source properties and ancestry and remain distinct from manually drawn default walls. Append supports normal undo/redo; source files and unrelated native Scene data remain unchanged.

Export JSON and image filenames use the set name, for example First floor.json and First floor.png, retaining the actual image extension. Separate region PNGs retain part numbers and exact final dimensions. Native Scene names, background/texture paths and every other original value remain unchanged in safe export; assign the renamed image manually in Foundry. The manager previews export filenames while allowing independent labels inside the project.

Import datasets from project appends selected complete sets. Export dataset to project appends the selected full current set to an existing .dale without opening it, including exact source image, geometry/raster edits, history and ancestry. Existing sets remain independent; colliding set names get a unique suffix. Concurrent target changes abort the export before atomic publication. Reusing identical image bytes does not link mutable edits.

New rectangle remains below New circle. Regions Ctrl+C/Ctrl+V uses a common contour clipboard across datasets. Move regions highlights the closest selected vertex before pressing; press freezes it as the grab point. Copy chooses the closest vertex in the same way. Two numeric buttons in Regions toggle point and horizontal/vertical guide alignment, sharing numeric tolerances with Vertices while retaining independent on/off states. Hold Alt to apply enabled rules; points take priority. The whole figure translates rigidly, surrounding lines and image pixels remain fixed. Release Alt for free movement, Escape to cancel. Scale/rotation preserve the same isolated membership; selection and selected PNG export remain whole after overlap/reopen.

The narrow arrow button at the left edge of the right panel hides/shows it. This visibility is remembered in portable preferences across launches; opening Settings reveals it. Information fills all remaining vertical space and only scrolls when its text overflows.

In Dataset manager, all JSON actions are below its filename field: Load JSON for an empty component, Replace JSON to replace the current file and contours, Merge contours to add another JSON while retaining current edits, To another dataset for move/copy, and Delete JSON. Merge contours is enabled when JSON or contours already exist. Image controls name the corresponding image operation. Hover over any button for a detailed explanation; manager captions have no ellipses.

The manager left column has a fixed320px width. Text-only New dataset/Delete dataset buttons share its top row equally at the same height as the other manager buttons; Import datasets/Export dataset share the row below the tree. The status text shares the bottom Cancel/Apply/Open row. There is no adjustable splitter or saved width.

In Regions, select one or more figures and press Del or click the eraser-icon Delete region button on the left. This removes only each selected exterior/hole boundary. Interior lines and scene-image pixels remain unchanged. Shared physical boundary segments are removed too; partial source lines retain the parts outside the boundary. Moved/pasted figures use their frozen line ownership, so coincident surroundings stay intact. Ctrl+Z restores the deletion; Ctrl+Y repeats it. Finish/cancel a gesture before deleting. Delete inside a focused numeric/text field continues editing that field.

Raster begins with Select raster regions. In either Regions or Raster, click to toggle the smallest closed cell. Drag more than10 screen pixels to draw a rectangle and invert every intersecting cell relative to the selection before dragging; changing the rectangle never repeatedly toggles cells. Escape restores that selection, including moved/pasted figures. An empty click clears all selection/highlights; an empty drag retains the previous selection.

Raster Remove inside/outside acts only on selected regions; both commands are disabled without selection. Each command stores an immutable boundary snapshot and one undo step. Changing selection or moving contours does not retarget it. Artwork offset changes the retained artwork on both sides using the same live value as PNG export. Preview edges now use PNG2x/bicubic smoothing, source alpha and the same halo rule. Native-size RGBA matches export; reduced preview remains a display projection. Original scene-image pixels remain unchanged.


### Arrange contour figures

Open Contours to arrange individual lines or connected shapes without changing extraction-cell selection in Regions. Click toggles one segment. Double-click selects all segments connected through shared vertices. Drag a selection rectangle more than10 screen pixels to invert intersected segments; empty click clears and Escape cancels. An unrelated crossing line stays separate.

A double-click uses the contour hit by its first click, even if the pointer shifts slightly toward a crossing line before the second click. With Select contours, the first click's provisional toggle is replaced by the complete contour selection and earlier intentional selections remain. With Move contours, the first target replaces the entire selection; an empty first hit clears it. Selection does not create copies or geometry edits. Copy/paste remains explicit Ctrl+C/Ctrl+V and placement.

Vertices, Contours and Regions keep separate on/off states for point and X/Y guide alignment. Switching off a button in one section leaves the others as set. Each section applies its own flags when activated, and project/dataset saving retains all of them. Numeric tolerances remain shared. Hold Alt for the enabled placement rules; points still take priority.

Press Del or use Edit > Delete contours to delete exactly the selected contour lines. Open and disconnected selections work; unselected crossing, coincident and neighbouring lines remain. One Ctrl+Z restores them; Ctrl+Y reapplies deletion. Finish/cancel a gesture first. Delete in a text/numeric field continues editing that field. Regions retains its own Delete region command.

Move drags all selected lines together; Ctrl+wheel scales. Rotate uses plain wheel in0.1-degree steps around the common center. The selected IDs stay fixed, so overlapping small rectangles do not cut a larger selected rectangle. Open lines and disconnected selections work too. Point and guide controls share Contours/Regions tolerances and require Alt; the nearest highlighted vertex is frozen as the grab point. Ctrl+C/V copies only contours across sets, with the same placement rules; raster stays in place.

The36px Select all button in Main, immediately left of Clear selection, shares Ctrl+A. Both select everything used by the current section: contour segments in Vertices/Contours and standard cells in Regions/Raster, within the selected height layer. Ctrl+Shift+A clears selections and pending previews. Inside a text/numeric field, Ctrl+A selects its text. PNG export and raster masks continue using standard closed-region calculations.


The line eraser highlights and deletes pieces between the nearest intersections or original endpoints. It includes crossings without existing shared vertices. A drag uses a frozen partition and one undo step; Escape cancels. Other crossing lines remain intact unless touched by the brush.

When a new cut endpoint or a moved contour point touches another figure, choose Yes to connect them, No to keep them independent even at exactly coincident coordinates, or Cancel to abort the edit. Do not ask again remembers that answer separately for Erase lines and Edit points. Right-click the tool's left button to choose a default action from the dropdown, including Ask every time. These editing relationships persist in .dale. Regions, raster masks and PNG export still calculate the complete geometric graph; native JSON has no editor independence tags.

Right-click settings show the actual question as a label with a default-action dropdown below. Ask every time corresponds to an unchecked remember box; the explicit actions correspond to remembered Yes/No. Automatic question dialogs retain their buttons and remember checkbox.

Consecutive wheel ticks in Rotate figures/Rotate regions form one history entry. Ctrl+Z returns to the start of rotation; Ctrl+Y returns to its final result. The next action or save ends the series; later rotation starts another entry.

Contours rotates around the midpoint of the complete selected line bounds. Multiple selected contours and open lines share one common center. The grabbed vertex used for move/paste alignment does not become a rotation pivot. Pasted Contours/Regions use the translated geometric center. Keep that center stable throughout a rotation series, including asymmetric shapes. A changed selection or selected geometry invalidates its cached center; project/dataset restoration derives it again from current geometry.

Export selected regions asks whether adjacent selections should be exported as one. Yes creates one PNG per connected selected group, removing internal boundaries before Artwork offset. No exports each selected cell separately. Unselected cells stay excluded and holes stay transparent. Exact edge/corner contacts and overlaps connect groups; separate groups remain separate even when expanded artwork margins overlap. Image dimensions and coordinates use the existing exact alpha calculation, also shown in Information. Scene contours and raster edits are unchanged.

The PNG folder browser opens the remembered output parent and proposes a free dataset-overlays folder name. Keep it for the default, type a new folder name or choose an existing folder. Files are saved directly in that final folder, including when entering it with a double-click. No extra export subfolder is added. PNG export remembers the browsing parent, so later exports can choose among the same asset folders. You can store other PNGs and Scene JSON in the same folder.

If a PNG, placement manifest or exported JSON already exists, the question shows its filename and containing-folder name. Overwrite replaces that file; Create copy keeps it and chooses a free name; Cancel stops the current export. PNG copies retain the exact dimensions at the end of their names. All PNG files and decisions are staged before publication. New folders publish atomically; existing-folder publication backs up overwritten files and removes new files/restores backups if cancelled or failed. Unrelated assets, original inputs and the open project remain protected. JSON uses the same question after its save picker, without a duplicate native overwrite prompt.

Do not ask again remembers either answer between launches. Right-click the left Export selected regions button to change it in the default-action dropdown; choose Ask every time to restore the question. Cancel stops before folder selection and writes nothing. File > Export PNGs uses the same question if regions are selected; without a selection it retains the normal connected-component export.


## Standard tool settings and grid-aligned PNGs

All fourteen numeric tools use48x48 icon buttons. A filled lower-right corner marks every button with a right-click settings action, including Edit vertices and Export selected regions. Right-click does not activate the tool or toggle alignment. Settings open in a nonmodal frameless container with a custom title and small X, starting at416px wide. It appears to the button's right inside the map where space permits and shifts upward near the bottom. Standard controls stack vertically: numeric field/arrows first, default action in the next group, then applicable PNG options, without extra separator lines. Container titles have a6px left inset, less than the controls inside. Every container has the same footer: equal-size Apply, then Cancel. Apply commits; Cancel, X, Escape, an outside click or another settings container discards staged changes. Opening a combo list inside does not dismiss its container. Automatic operation questions retain their existing buttons and remember checkbox. Ctrl+wheel and project/global numeric scope remain available.

Export selected regions > right-click > PNG dimensions > Size to grid defaults off and remembers its choice in portable preferences. It applies to selected, adjacent-group and all-region PNG export. Exact alpha bounds are calculated after Artwork offset, current mask/brush edits, original alpha and bicubic edge pixels. The canvas then expands to grid boundaries with transparent padding; the artwork is not stretched or moved. Padding may extend beyond the scene image. Information, filename dimensions, PNG source offsets and placement.json all describe the padded canvas; content_bounds still describes its original nonzero pixels.

The square grid comes from the active dataset's Scene JSON, accepting Dungeon Alchemist's numeric grid and modern grid.size/type. Source/scene scaling and background offset determine cell size and grid phase separately on X/Y. This preserves the working editor coordinate frame; existing nonzero-padding alignment warnings remain. A valid square grid and whole-pixel source boundaries are required. Missing/invalid grids, hex/gridless scenes, fractional source-pixel boundaries and nonzero legacy shifts show an explicit reason. Disable Size to grid to retain the normal exact crop; the100px drawing fallback is never used for export alignment.


## Acquire a temporary alignment reference

Enable the current section's guide-alignment button. While moving a vertex, contour or region, hover another stationary vertex with the cursor, then move away: its hollow gold marker confirms it was remembered. Hold Alt to align the original grabbed point horizontally or vertically to remembered vertices. Several points can be remembered during one gesture; they take priority over ordinary axis candidates within the configured guide tolerance. The contour moves rigidly and its grab point does not change. Alt release temporarily removes the constraint, retaining references until release/commit or cancellation.

The same behavior applies when placing copied outlines and stretching a new line or rectangle. References come only from the visible height scope and never from the moving geometry. Hovering does not join contours or change wall properties. Commit, Escape, Clear selection, changing tools or opening another dataset/project clears the temporary references.

### Selection groups

Open the checked manager icon in Groups, immediately after Main. The compact floating panel stays open while editing; drag its header to reposition or snap to a visible editor-area edge. It stays fixed while panning or zooming the map. A free panel moves left when the editor area shrinks; deliberate side/corner docks follow that area's size. Drag the bottom-right grip to resize only the manager; its custom dimensions survive group changes and hide/reopen within the session. X or the same toolbar button closes it. Click the standalone + to create a group. Each group block contains a color swatch, name and small + / - / x buttons: add current selection, exclude current selection, delete only the group after confirmation. Double-click a group name to rename; click the swatch for the standard RGB color picker. Click a group name or choose it in the top dropdown to select its elements in the current section.

Groups belong to the current section of the current dataset and save in .dale; an element may belong to several groups. While the manager is open, group lines use their group color in the center pixel at unchanged3px total width and selected grouped regions become opaque in their group color. The active group takes priority; with All group colors selected, the latest assigned group wins overlaps. Closing restores ordinary colors without changing membership. Region groups use their actual boundary lines; crossing interior lines are excluded. Grouping changes neither geometry nor raster/export colors. Geometry undo/redo preserves identity-based membership; group management itself is immediate editor metadata rather than a geometry history operation.

With Select contours, double-click toggles the whole connected contour: a fully selected contour is deselected; partial or unselected contours are selected entirely. Other selected contours remain selected.

Undo retains up to100 recent actions per dataset. Older geometry becomes a protected baseline, keeping current contours, raster edits and ancestry. Existing schema7 projects still open and save directly. Saving may shorten the undo tail further for very large datasets to keep the catalog within its safety limit; current content is never discarded. Project Save as suggests the name without an extension; .dale is added automatically.


In Regions, choose a group and click Export selected regions. PNG export asks Dataset name or Group name when the selected cell boundaries match a complete group. The question shows both names and can remember the choice. Right-click Export selected regions to select Ask every time, Dataset name or Group name later. Unmatched parts keep the dataset name. The active matching group takes priority, otherwise the latest assigned match wins. Artwork offset/grid padding do not prevent an original boundary match; stable selection/part numbers, exact pixel-size suffixes and PNG placement stay the same under either name. Single-group exports, including multiple PNG parts, also name the physical package JSONs and suggested folder after the group; mixed packages keep dataset JSON names. Native names/paths inside Scene JSON stay untouched. Preparation errors are shown before starting the worker and do not leave export disabled.

The map editor has no outer gutters. Its frame and scrollbars fill the available central height, with the tool strip directly adjacent on the left. The tool strip gains scrollbar width only when its tools exceed the available height.

Copied Contours/Regions retain wall properties and exact provenance but start outside all selection groups, even within the same set. Assign copies explicitly with the manager + control. Splits and moves of existing members retain their groups.


In Vertices, Alt enables the checked angle/contour-axis rules. Accepted angle/axis rules retain their existing precedence; disabling ordinary snapping still disables that fallback.

Only the active section's selection is displayed. Returning to a section restores its retained selection; Hand keeps that section's highlights visible. Regions and Raster have independent cell selections, and Raster masks use only Raster's selected cells. Clear selection affects the current section. Saving/opening a dataset retains both cell choices and any detached Regions shape without exposing them in Vertices or Contours. Topology changes discard stale cell choices; committed Vertices edits still clear transform selection as described above.

A vertex snapped to the interior of an angled wall stays geometrically closed while sliding along it, including fractional source coordinates. The analysis reconciles floating-point contacts; it does not move the target wall or change the configured screen-pixel snap distance. Alt angle/axis rules and ordinary point-first snapping retain their existing behavior.

Custom Colors belongs to the complete .dale project, shared by every dataset and color picker. Add or replace slots in the standard color dialog, then save the project to retain them for reopening. Cancelling the selected object's color still retains changes made to Custom Colors and marks the project unsaved. Another project/window has its own palette. Dataset import/export leaves the destination project's palette in place; new documents start with empty white slots.

For a group with holes, select the outer minimum cells in Regions and deselect the cells that should be transparent, then press the group's +. Group selection restores that exact choice. Select a stored cell and press - to remove it; + adds it back. Shared walls stay intact. Export selected regions combines only included cells and retains hole transparency, the chosen group/dataset prefix, stable numbers and exact dimensions. Existing groups are not rewritten automatically.

Raster has round/square erase and restore tools, each showing its diameter in source pixels. Ctrl+wheel changes size; Alt+wheel adjusts the width of the soft outer band. Right-click a brush for size, shape, feather and overall pressure. Apply commits settings; Cancel/X/Escape/outside-click leaves them unchanged. The center remains solid until the chosen feather band reaches it. A stroke is one undo step and behaves the same in previews and PNGs.

Toggle Raster crosshair for translucent dashed cursor axes. Toggle Raster rulers for top/left rulers; right-click for px/ft/cm/mm units, whole-value guide snapping, automatic grid and its spacing. World units use the scene's declared grid and mean game-world distance. Without grid metadata use pixels. Drag from the top ruler for a horizontal guide or the left ruler for a vertical guide. Ctrl+drag repositions a guide; returning it to a ruler deletes it; Escape cancels. Guides/grid stay at source coordinates while panning or zooming and never appear in exported PNGs. Settings and guides belong to each dataset and save in .dale.

Native raster resolution displays visible tiles at original image resolution with the current alpha edits, without changing camera or zoom. It uses the overview while zoomed out or during an active gesture, then restores native tiles. It does not restore erased pixels or change export quality. Disable the toggle to return to the lightweight overview. The toggle is saved separately for each dataset.

The group manager retains its current list position when selecting, assigning, excluding, renaming, recoloring, adding or deleting a group. It does not scroll automatically to the bottom; deleting enough rows clamps the position only to the remaining range. Wheel, scrollbar and ordinary keyboard navigation remain available.

Crosshair and rulers/guides now live in the top Main panel and work in every editing section, including Hand. Their settings still belong to each dataset. Right-click rulers for units, guide snapping and automatic grid. Native image quality remains active when changing sections after enabling its Raster button.

Native resolution prepares a lossless disk cache on first use, keeping the lightweight overview responsive until visible tiles are ready. Large maps no longer require two full decoded image copies in RAM. At zoom1 or closer, visible source pixels keep their exact resolution; zoomed-out views use appropriately sampled tiles. The portable Cache folder sits next to DALE.exe and may temporarily need roughly the decoded image size, e.g.751MiB for16200x16200RGB. Current-project cache is removed on project/source replacement and normal closing; stale files from crashes are cleaned on next opening, while other running DALE instances keep their own active caches. Original images, project files and UserData are never cache-cleanup targets.

Inline Raster brush size fields are half their previous height and stay within the tool buttons. The same values remain editable at standard size in the right-click settings popup.

The Modes tabs use the same framed panel as Main, with rounded upper corners and square lower corners. Move by dragging or scale with Ctrl+wheel; the Scale tool uses the wheel. Rotate uses configured ordinary/Alt steps and a cumulative angle caption. Escape cancels an unfinished drag; undo restores geometry and imagery together. Regions tools continue to transform geometry while leaving pixels in place.

Scene annotations are not exported.

Keep the complete _internal folder. UserData, Cache, imported assets and projects remain local and ignored. Git preserves every bundled file byte for byte, including vendor code/licenses.
