# Editing workflow

On Windows, double-click **run.cmd** in the repository root. First launch prepares `.venv` if it is missing; 64-bit Python 3.11+ is required. For debugging with console output, use `.\.venv\Scripts\python.exe -m dale`. The agent can preload a pair using `--image <JPG path> --scene <JSON path>`.

1. Export a JPG and its Foundry scene JSON from Dungeon Alchemist. Keep equal canvas sizes and grid origins across floor exports. Orthographic/top-down output is the initial validation target.
2. Keep the complete ground-level JPG for the base map. Open an upper-floor JPG + JSON pair in DALE using **Open pair**.
3. Inspect cyan source wall lines. Wheel zooms around the cursor. Hold the **right mouse button** and drag to move the map with the cursor in any tool, including at fit zoom. **Pan** mode also supports left-button drag; **Fit** restores the full-map view. Toggle walls when reviewing pixels.
4. Review dimensions, import warnings, and alignment. For padded scenes, enter the actual **Scene origin X/Y** in source-scene pixels and apply alignment. The editor does not guess padding offsets. Changing alignment starts a fresh editing session after confirmation.
5. Inspect orange unresolved lines. Set **Join gaps up to (px)** to connect small gaps automatically; 0 disables it. Distances use original image pixels. Both end-to-end gaps and end-to-middle T junctions are supported; exact T intersections need no tolerance. Purple lines show the generated joins. For larger or intentional repairs, choose **Closure**: plain click near an original wall to snap the start, Ctrl-click or Alt-click for free corners, then plain click near an original wall to snap the end. The yellow path is editor-only. Escape cancels an unfinished closure.
6. Set **Contour offset (px)** if needed: positive expands the boundary, negative shrinks it. Green shows the effective boundary. Choose **Remove outside** to keep its interiors, or **Remove inside** to erase them. If no closed region exists, repair it first. If unresolved lines coexist with usable regions, inspect and explicitly continue or repair. An inward offset that eliminates every region is rejected. Applied masks are snapshots: undo the previous mask and apply again to replace it after changing closures, gap tolerance, or offset. Changing the settings alone only updates the contour preview.
7. Choose **Erase**, set the brush diameter in original image pixels, and drag across unwanted objects. Choose **Restore** to recover source opacity. Each complete stroke is one undo step. **Undo/Redo** also covers closures and contour masks. Checkerboard areas are transparent.
8. Choose **Foundry 13** or **Foundry 14** and an **Elevation (ft)**. Presets run from -20 to 100 ft in 5-ft steps. Type a custom integer for 1-ft precision (for example 17 or -3); fractions are rejected.
9. Choose **Export PNG**. Export uses the original resolution, preserves alignment and decoded source RGB, and excludes all wall/closure overlays. Large exports show progress and can be cancelled. The original JPG and JSON remain unchanged. The default name includes elevation; PNG metadata records target/elevation for reference. **Foundry does not automatically apply PNG placement metadata.**
10. Repeat for other upper floors. In Foundry 13 use the intended tile/module floor workflow; in Foundry 14 use native Scene Levels as appropriate. Configure elevation, scene units, and visibility in Foundry. Exact installation behavior remains to be validated; the editor currently exports imagery rather than a ready-to-import floor scene.

Edits are currently in memory. Closing or replacing an edited map asks before discarding changes; PNG export is not a reloadable DALE session. Persistent project save/load is planned. The reduced preview is intended for layout and alpha inspection; export retains original source pixels.
