# PNG contour editor workflow

DALE prepares separate transparent PNGs from one source image at a time. Level assembly, wall types, heights, presets, lights and portals are configured manually in Foundry. See ADR-020.

1. Open DALE/DALE.exe. Open Dataset manager (Ctrl+I), then add a scene image (JPEG, PNG, WebP, BMP or TIFF) or Scene JSON to the selected set. A same-stem JSON opens with an image imported into a completely empty set. JSON is optional. Add/Replace JSON also offers original/current documents from a current .dale archive. Apply or Open dataset commits the staged changes.
2. Check alignment and closed/open contours. Vertices provides point editing, new lines/circles, line/point erasers and vertex-first snapping. Closed lines are cyan, unresolved lines red. Shared points move together; Alt applies only enabled angle/contour alignment buttons (below). Each edit preserves source ancestry and undo/redo.
3. Join gaps with directional Auto-close near the cursor or Close all contours across the map. Each has its own tolerance and a white preview followed by Cancel/Yes; no-op dialogs have only Close. They extend or shorten free tips along their line vectors to intersections within the tool's tolerance, with separate counts in the confirmation. Retractions stop at existing contacts and never collapse/reverse a wall. Shared walls retain every covered-layer joint. No sideways bridges are added. NEXT-009 remains an open report about region-transform isolation.
4. Regions selects minimum closed cells; click toggles, empty space clears. Move/scale/rotate changes geometry, leaving raster fixed. Artwork offset retains/cuts source pixels around boundaries. Remove outside/inside applies an immutable alpha mask. Raster Erase/Restore cleans opacity; original source alpha is the upper bound.
5. Choose All regions for connected closed objects, or select individual cells and use Export selected regions. Every output is a separate native RGBA PNG, cropped to every nonzero final alpha pixel, including faint bicubic edges and clipped to the source image. Filenames include exact output dimensions, for example map-part-001-702x702px.png. Information uses the same exact bounds. placement.json records source/scene XY and dimensions for manual placement, without heights or gameplay settings. Export is cancellable and atomically publishes a new folder.
6. Save a current schema7 .dale to retain exact source bytes, contours, mask snapshots, strokes, ancestry, undo/redo, selection and settings. Older formats are rejected without migration. Recent projects lists up to10 successful paths. Copy the whole portable DALE folder; keep UserData/settings.json for preferences.

Top panels are Sections (Vertices/Contours/Regions/Raster), Main (Hand, Select all, Clear selection, Fit, Show contours, Settings) and Dataset (manager icon and set selector). Right Project contains Regions/File information; Settings contains language/global numeric settings. Both include the same contextual Information block. Ten numeric values retain independent project/global scope. Ctrl+wheel changes the active/hovered numeric value (Move regions scales); Rotate regions uses plain wheel. Right-drag pans in every tool. Escape cancels gestures; Ctrl+Shift+A clears selection without editing. Actual command shortcuts are listed in Information/tooltips in English/Russian. No level/preset/property-brush navigation remains.

Button hover help separates Purpose, Condition and Keys. The purpose explains the outcome, conditions state required selection/data/toggle state, and keys are listed with their effect. Numeric buttons include units; hovering their value field explains only that value. Help wraps to a readable width and does not accumulate repeated descriptions when switching language or mode.

Opening a dataset centers the camera on its scene frame while keeping its zoom. This also applies to the first dataset when reopening a project. Applying manager changes to the already active dataset preserves the current pan.

Edit contours by height layers filters visible wall editing. It does not disable erasers, point insertion/deletion or any geometry tool. Export JSON retains all other Scene data in every editing mode; only the current walls change. New lines/circles/rectangles work in All with ordinary unbounded wall defaults; choosing a range assigns those bounds. Split parts inherit original wall properties; manually drawn walls start with ordinary defaults. Original files remain unchanged.

## Repair contours by source height

Dataset manager can add Scene JSON before loading an image. JSON-only input and paired native wall-height input enable Edit contours by height layers in File information. Height bands are inferred from original wall bounds, with one canonical wall shared across every band it spans. Missing/null module bounds are unbounded; adjacent ranges only touching at their height boundary are processed separately.

Use cursor Auto-close or Close all contours, review the highlighted proposals and confirm Yes. The UI tolerance is in screen pixels and depends on zoom. A repair retains native IDs and wall records; internal intersections do not become exported fragments. Conflicting groups remain unchanged and the dialog reports their original contour numbers (one-based). Invalid height bounds are also retained/reported. Each accepted repair is one undo step, preserved in schema7 history/redo.

Point dragging and New line are available here. Choose a height band or exact range in the right dropdown; shared walls participate without clones. Point movement follows overlapping-height contacts, keeping independent coincident floors fixed. New lines/circles/rectangles use ordinary wall defaults and the selected range, or unbounded heights in All. Insertion, deletion, splitting and both geometry erasers are available; inherited wall settings are preserved. Each manual drag/new line is one undo step. Disable the checkbox to edit all contours together. Original source bytes remain frozen in the project. Export JSON preserves all other native Scene bytes/settings in this mode, changing only the walls array.


## Reuse contours and align points

File > Export JSON… (Ctrl+Shift+J) always saves the current contours of the active dataset, including unsaved ordinary geometry changes or safe repairs. All current lines are included regardless of height/region selection or contour visibility; redo, raster masks and Artwork offset are excluded. It works without an input JSON. The proposed physical filename uses the dataset name. Export does not switch sets, save the project or clear undo/redo. Finish/cancel active gestures first. Imported inputs, the open project and their hardlinks cannot be overwritten. When source JSON exists, export retains all non-wall Scene bytes in every mode; without source JSON, export writes a DALE contour snapshot. The same Export JSON command always uses the active set, never the project root or another catalog document. The old Export repaired JSON label has been replaced.

Dataset manager > Scene JSON > Add/Replace > choose a current .dale > Current contours (DALE) > Import loads applied contours, including existing schema7 projects without resaving. Save JSON copies the selected document without importing. This snapshot is for DALE, not a complete Foundry Scene. Original/stored JSON stays available separately.

Enable either/both numeric buttons in the left Vertices panel, then hold Alt while dragging a point. Right-angle alignment snaps a joint to90 degrees relative to adjacent lines, including rotated contours; highlighted legs and a square mark identify the joint. Contour alignment projects X/Y to vertices in the same connected contour/region, using thin dashed guides. Independent1..9999 screen-pixel tolerances default14; arrows/input/Ctrl+wheel adjust each. Both buttons default off. Release Alt for ordinary movement; Escape cancels. Numeric settings follow project/global precedence; toggles save with the project.


## Manage named datasets

The top Dataset toolbar contains one dataset dropdown and a36px manager button on its left. Each set owns optional current contours/JSON, one scene image, independent edits/redo, source ancestry and project tool values. Switching the dropdown opens both components together. Open the Dataset manager (Ctrl+I) for the approved tree/properties interface.

Create empty sets; rename the set or each file independently. Delete JSON removes its current contours while retaining the image; delete image retains contours. Last-set deletion leaves a new empty set. The first remaining set opens on the next project launch. File commands that manipulate components have moved into this manager; Open/Save project, Recent projects, quick Export JSON/PNG, Close project and Exit remain in File.

Drag a JSON/image child onto another set, or use Transfer. Choose Move, Copy or Cancel. Occupied destinations explicitly offer replacement. A copy is independent; a move clears only that source component. Transfer uses current contours or raster edits, retains exact provenance, and does not automatically rescale coordinates for a differently sized image. A component import freezes source bytes. Apply commits the staged manager changes to the working project; Cancel discards unapplied work. Open dataset applies and activates the selected set. Save project writes every set, including inactive/empty ones.

Merge contours appends imported contours, preserving existing edits, line identities and raster. Full duplicate coordinates/properties may skip; different heights, doors and flags coexist. It creates one combined current JSON. In Preserve JSON mode, imported additions keep their exact source properties and ancestry and remain distinct from manually drawn default walls. Append supports normal undo/redo; source files and unrelated native Scene data remain unchanged.

Export JSON and image filenames use the set name, for example First floor.json and First floor.png, retaining the actual image extension. Separate region PNGs retain part numbers and exact final dimensions. Native Scene names, background/texture paths and every other original value remain unchanged in safe export; assign the renamed image manually in Foundry. The manager previews export filenames while allowing independent labels inside the project.

Import datasets from project appends selected complete sets. Export dataset to project appends the selected full current set to an existing .dale without opening it, including exact source image, geometry/raster edits, history and ancestry. Existing sets remain independent; colliding set names get a unique suffix. Concurrent target changes abort the export before atomic publication. Reusing identical image bytes does not link mutable edits.

New rectangle remains below New circle. Regions Ctrl+C/Ctrl+V uses a common contour clipboard across datasets. Move regions highlights the closest selected vertex before pressing; press freezes it as the grab point. Copy chooses the closest vertex in the same way. Two numeric buttons in Regions toggle point and horizontal/vertical guide alignment, sharing numeric tolerances with Vertices while retaining independent on/off states. Hold Alt to apply enabled rules; points take priority. The whole figure translates rigidly, surrounding lines and image pixels remain fixed. Release Alt for free movement, Escape to cancel. Scale/rotation preserve the same isolated membership; selection and selected PNG export remain whole after overlap/reopen.

The narrow arrow button at the left edge of the right panel hides/shows it. This visibility is remembered in portable preferences across launches; opening Settings reveals it. Information fills all remaining vertical space and only scrolls when its text overflows.

In Dataset manager, all JSON actions are below its filename field: Load JSON for an empty component, Replace JSON to replace the current file and contours, Merge contours to add another JSON while retaining current edits, To another dataset for move/copy, and Delete JSON. Merge contours is enabled when JSON or contours already exist. Image controls name the corresponding image operation. Hover over any button for a detailed explanation; manager captions have no ellipses.

The manager left column has a fixed320px width. Text-only New dataset/Delete dataset buttons share its top row equally at the same height as the other manager buttons; Import datasets/Export dataset share the row below the tree. The status text shares the bottom Cancel/Apply/Open row. There is no adjustable splitter or saved width.

In Regions, select one or more figures and press Del or click the eraser-icon Delete region button on the left. This removes only each selected exterior/hole boundary. Interior lines and scene-image pixels remain unchanged. Shared physical boundary segments are removed too; partial source lines retain the parts outside the boundary. Moved/pasted figures use their frozen line ownership, so coincident surroundings stay intact. Ctrl+Z restores the deletion; Ctrl+Y repeats it. Finish/cancel a gesture before deleting. Delete inside a focused numeric/text field continues editing that field.

Raster begins with Select raster regions. In either Regions or Raster, click to toggle the smallest closed cell. Drag more than10 screen pixels to draw a rectangle and invert every intersecting cell relative to the selection before dragging; changing the rectangle never repeatedly toggles cells. Escape restores that selection, including moved/pasted figures. An empty click clears all selection/highlights; an empty drag retains the previous selection.

Raster Remove inside/outside acts only on selected regions; both commands are disabled without selection. Each command stores an immutable boundary snapshot and one undo step. Changing selection or moving contours does not retarget it. Artwork offset changes the retained artwork on both sides using the same live value as PNG export. Preview edges now use PNG2x/bicubic smoothing, source alpha and the same halo rule. Native-size RGBA matches export; reduced preview remains a display projection. Original scene-image pixels remain unchanged.


### Arrange contour figures

Open Contours to arrange individual lines or connected shapes without changing extraction-cell selection in Regions. Click toggles one segment. Double-click selects all segments connected through shared vertices. Drag a selection rectangle more than10 screen pixels to invert intersected segments; empty click clears and Escape cancels. An unrelated crossing line stays separate.

A double-click uses the contour hit by its first click, even if the pointer shifts slightly toward a crossing line before the second click. The first click's provisional toggle is replaced by the complete contour selection; earlier intentional selections remain. Selection does not create copies or geometry edits. Copy/paste remains explicit Ctrl+C/Ctrl+V and placement.

Vertices, Contours and Regions keep separate on/off states for point and X/Y guide alignment. Switching off a button in one section leaves the others as set. Each section applies its own flags when activated, and project/dataset saving retains all of them. Numeric tolerances remain shared. Hold Alt for the enabled placement rules; points still take priority.

Press Del or use Edit > Delete contours to delete exactly the selected contour lines. Open and disconnected selections work; unselected crossing, coincident and neighbouring lines remain. One Ctrl+Z restores them; Ctrl+Y reapplies deletion. Finish/cancel a gesture first. Delete in a text/numeric field continues editing that field. Regions retains its own Delete region command.

Move drags all selected lines together; Ctrl+wheel scales. Rotate uses plain wheel in0.1-degree steps around the common center. The selected IDs stay fixed, so overlapping small rectangles do not cut a larger selected rectangle. Open lines and disconnected selections work too. Point and guide controls share Contours/Regions tolerances and require Alt; the nearest highlighted vertex is frozen as the grab point. Ctrl+C/V copies only contours across sets, with the same placement rules; raster stays in place.

The36px Select all button in Main, immediately left of Clear selection, shares Ctrl+A. Both select everything used by the current section: contour segments in Vertices/Contours and standard cells in Regions/Raster, within the selected height layer. Ctrl+Shift+A clears selections and pending previews. Inside a text/numeric field, Ctrl+A selects its text. PNG export and raster masks continue using standard closed-region calculations.


The line eraser highlights and deletes pieces between the nearest intersections or original endpoints. It includes crossings without existing shared vertices. A drag uses a frozen partition and one undo step; Escape cancels. Other crossing lines remain intact unless touched by the brush.

When a new cut endpoint or a moved contour point touches another figure, choose Yes to connect them, No to keep them independent even at exactly coincident coordinates, or Cancel to abort the edit. Do not ask again remembers that answer separately for Erase lines and Edit points. Right-click the tool's left button to change the answer or clear the checkbox to restore questions. These editing relationships persist in .dale. Regions, raster masks and PNG export still calculate the complete geometric graph; native JSON has no editor independence tags.

Every right-click question setting shows the actual question first, followed by the instructions for remembering or resetting its answer. This includes both contour-connection tools and adjacent-region PNG export.

Consecutive wheel ticks in Rotate figures/Rotate regions form one history entry. Ctrl+Z returns to the start of rotation; Ctrl+Y returns to its final result. The next action or save ends the series; later rotation starts another entry.

Export selected regions asks whether adjacent selections should be exported as one. Yes creates one PNG per connected selected group, removing internal boundaries before Artwork offset. No exports each selected cell separately. Unselected cells stay excluded and holes stay transparent. Exact edge/corner contacts and overlaps connect groups; separate groups remain separate even when expanded artwork margins overlap. Image dimensions and coordinates use the existing exact alpha calculation, also shown in Information. Scene contours and raster edits are unchanged.

Do not ask again remembers either answer between launches. Right-click the left Export selected regions button to change it; clear the checkbox to restore the question. Cancel stops before folder selection and writes nothing. File > Export PNGs uses the same question if regions are selected; without a selection it retains the normal connected-component export.
